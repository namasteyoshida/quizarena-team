# 1. 目的・背景

### このアプリで何を実現するか
研修で学んだJavaScript・TypeScript・Reactの知識を活用し、自分たちで作成したクイズを出題・回答できるアプリを作成する。

### 想定利用者
研修受講者、プログラミング学習者

# 2. 機能一覧

| ID | 機能名 | 概要 | 備考 |
|----|--------|------|------|
| F-1 | 作問フォーム | 問題文・選択肢・正解・解説・制限時間・カテゴリを入力し、新しい問題を登録する。登録後は一覧へ即時反映する。 | React Hook Form + Yupを使用 |
| F-2 | スタート画面 | 出題カテゴリと出題順（登録順・シャッフル）を選択してクイズを開始する。 | |
| F-3 | 制限時間タイマー | 問題ごとに制限時間をカウントダウン表示し、0秒になると自動で時間切れとして解説画面へ進む。 | |
| F-4 | 回答・判定 | 選択肢をクリックすると正誤判定を行い、結果と解説を表示する。正解した場合はスコアを加算し、タイマーを停止する。 | |
| F-5 | 次の問題へ | 「次へ」ボタンで次の問題へ進み、タイマーを初期値へリセットする。最後の問題終了後は結果画面へ遷移する。 | |
| F-6 | 結果・復習 | 正答数・正答率・所要時間を表示し、不正解だった問題のみ復習一覧として表示する。「もう一度」で最初からやり直せる。 | |
| F-7 | 状態管理 | クイズの進行状況やスコアなどをuseReducerで管理する。 | |

# 3. 挙動要件（非機能）

| ID | 挙動要件 | 期待する具体的な動き |
|----|----------|----------------------|
| T-1 | タイマーのリセット | 次の問題へ進むたびに、その問題の制限時間からカウントダウンを開始する。 |
| T-2 | 回答後の停止 | 回答後または時間切れ後はタイマーを停止し、0秒未満にはならない。 |
| T-3 | クリーンアップ | 問題切替や画面遷移時にsetIntervalを解除し、タイマーが重複して動作しないようにする。 |
| T-4 | 二重回答防止 | 一度回答した問題は再度選択肢を押しても判定やスコアが変化しない。 |

# 4. データ定義

## Category

```ts
export type Category = 'JavaScript' | 'TypeScript' | 'React';
```

## Choice

```ts
export type Choice = {
  id: string;
  label: string;
};
```

## Question

```ts
export type Question = {
  id: string;
  text: string;
  choices: Choice[];
  correctChoiceId: string;
  explanation: string;
  timeLimitSec: number;
  category: Category;
};
```

追加プロパティは使用しない。

- 初期問題データ件数：9問
- カテゴリ内訳
  - JavaScript：3問
  - TypeScript：3問
  - React：3問

# 5. バリデーション仕様

| フィールド | ルール | エラーメッセージ |
|------------|--------|------------------|
| 問題文 | 必須・5～200文字・前後空白削除 | 問題文は5文字以上で入力してください。 |
| 選択肢1～4 | 必須・60文字以内・重複不可 | 選択肢が重複しています。 |
| 正解 | 必須・1～4のいずれか | 正解を選択してください。 |
| 解説 | 必須・10文字以上 | 解説は10文字以上で入力してください。 |
| 制限時間 | 必須・整数・5～120秒 | 制限時間は5～120秒で入力してください。 |
| カテゴリ | 必須・JavaScript・TypeScript・Reactのいずれか | カテゴリを正しく選択してください。 |

## 使用する transform

- `trim()` を使用し、問題文・選択肢・解説の前後の空白を削除する。

## 使用する独自 test

- 4つの選択肢に重複がないことを確認する。

# 6. 判断ログ

| # | 論点（どこが曖昧だったか） | 決めたこと | 理由 |
|---|---------------------------|------------|------|
| 1 | 初期問題数 | 8問（各カテゴリ2.2.4問）用意する | 各カテゴリを均等にし、課題条件を満たすため。 |
| 2 | シャッフル方法 | Fisher-Yatesアルゴリズムを使用する | 偏りの少ないランダムな出題順を実現するため。 |
| 3 | 時間切れ時の扱い | 不正解として判定し、自動で解説画面を表示する | 採点ルールを分かりやすくし、復習対象へ含めるため。 |
