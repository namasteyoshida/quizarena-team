# 2. 機能一覧

| ID | 機能名 | 概要 | 備考 |
|----|--------|------|------|
| F-1 | 作問フォーム | 問題文・選択肢・正解・解説・制限時間・カテゴリを入力し、新しい問題を登録する。登録後は一覧へ即時反映する。 | React Hook Form + Yupを使用 |
| F-2 | スタート画面 | 出題を始める前に、カテゴリ(すべて/JavaScript/TypeScript/React)と出題順(登録順またはシャッフル)を選べるようにする。カテゴリを分けて選べるようにしたのは、苦手分野だけを繰り返し練習したいという使い方にも対応するため。 | |
| F-3 | 制限時間タイマー | 問題ごとに制限時間をカウントダウン表示し、0秒になると自動で時間切れとして解説画面へ進む。 | |
| F-4 | 回答・判定 | 選択肢を選んだ瞬間に正誤を判定し、正解/不正解と解説をその場で表示する。正解の場合のみスコアを加算し、同時にタイマーを止める。判定を「選んだ瞬間」に行うのは、決定ボタンを別に用意すると操作が一手間増え、テンポの良くするため。 | |
| F-5 | 次の問題へ | 「次へ」ボタンを押すと次の問題に移り、タイマーはその問題の制限時間で最初からカウントし直す。最後の問題に回答した後だけは「次へ」ではなく結果画面に遷移する。問題ごとにタイマーを完全にリセットするのは、前の問題の残り時間が引き継がれると採点の公平性が崩れるため。 | |
| F-6 | 結果・復習 | クイズ終了後は正答数・正答率・かかった時間を表示し、間違えた問題だけを抜き出して復習リストとして見せる。正解した問題まで並べると復習の効率が落ちるため、あえて不正解だった問題だけに絞っている。「もう一度」を押すとスコアや回答履歴を含めて状態を全てidleに戻し、最初から挑戦し直せるようにする。 | |
| F-7 | 状態管理 | クイズの進行状態(出題前/出題中/解説中/終了)や現在の問題番号、スコア、回答履歴といった複数の値を、useReducerでひとつのreducer関数にまとめて管理する。これらの値は「回答する」という1つの操作で同時に変化するため、useStateを複数並べるより、ひとつのactionから状態遷移をまとめて記述できるuseReducerの方が処理の流れを追いやすいと判断した。 | |

# 3. 挙動要件（非機能）

| ID | 挙動要件 | 期待する具体的な動き |
|----|----------|----------------------|
| T-1 | タイマーのリセット | 次の問題に進むたびに、その問題ごとに設定された制限時間からカウントダウンを開始し直す。前の問題の残り時間を引き継いでしまうと、問題によって実質の解答時間が変わってしまい、採点の公平性が崩れるため、切り替え時は必ず制限時間から再スタートさせる。
 |
| T-2 | 回答後の停止 | 回答した後、または時間切れになった後は、その時点でカウントダウンを止め、以後は数字が変化しないようにする。0秒を下回って表示されると「マイナスの残り時間」という意味不明な状態になり、ユーザーが混乱するため、0で確実に止める設計にした。 |
| T-3 | クリーンアップ | 問題が切り替わる時や画面が切り替わる(アンマウントされる)時には、動いているカウントダウン処理(setInterval)を必ず解除する。解除を忘れると、古いタイマーが裏で動き続けたまま新しいタイマーも動き出し、カウントダウンが二重に進んで表示が実際の経過時間とズレる不具合につながるため、切り替えのタイミングで必ず後片付けをする。 |
| T-4 | 二重回答防止 | 一度選択肢を選んで回答が確定した後は、同じ問題に対して別の選択肢を押しても、判定結果やスコアが変化しないようにする。回答済みかどうかを状態として持たせておかないと、ユーザーが解説を見ながら選択肢を連打してスコアを不正に増やせてしまうため、一度確定した回答は上書きされないようにしている。 |

# 4. データ定義

## Category

```ts
export type Category = 'JavaScript' | 'TypeScript' | 'React';
```

## Choice

```ts
export type Choice = {
  id: string;
  label: string;
};
```

## Question

```ts
export type Question = {
  id: string;
  text: string;
  choices: Choice[];
  correctChoiceId: string;
  explanation: string;
  timeLimitSec: number;
  category: Category;
};
```

追加プロパティは使用しない。

- 初期問題データ件数：9問
- カテゴリ内訳
  - JavaScript：3問
  - TypeScript：3問
  - React：3問

# 5. バリデーション仕様

| フィールド | ルール | エラーメッセージ |
|------------|--------|------------------|
| 問題文 | 必須・5～200文字・前後空白削除 | 問題文は5文字以上で入力してください。 |
| 選択肢1～4 | 必須・60文字以内・重複不可 | 選択肢が重複しています。 |
| 正解 | 必須・1～4のいずれか | 正解を選択してください。 |
| 解説 | 必須・10文字以上 | 解説は10文字以上で入力してください。 |
| 制限時間 | 必須・整数・5～120秒 | 制限時間は5～120秒で入力してください。 |
| カテゴリ | 必須・JavaScript・TypeScript・Reactのいずれか | カテゴリを正しく選択してください。 |

## 使用する transform

- `trim()` を使用し、問題文・選択肢・解説の前後の空白を削除する。

## 使用する独自 test

- 4つの選択肢に重複がないことを確認する。

# 6. 判断ログ

| # | 論点（どこが曖昧だったか） | 決めたこと | 理由 |
|---|---------------------------|------------|------|
| 1 | 初期問題数 | 8問（各カテゴリ2.2.4問）用意する | 各カテゴリを均等にし、課題条件を満たすため。 |
| 2 | シャッフル方法 | Fisher-Yatesアルゴリズムを使用する | 偏りの少ないランダムな出題順を実現するため。 |
| 3 | 時間切れ時の扱い | 不正解として判定し、自動で解説画面を表示する | 採点ルールを分かりやすくし、復習対象へ含めるため。 |
